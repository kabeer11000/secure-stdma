================================================================================

| Plain STDMA Header              |              20 |

Security Overhead:
  Plain -> Secure+Sig:                          +135 bytes per packet
  With certificate (every 10th packet):         +411 bytes
  Average per-packet overhead (10:1 cert ratio): ~105 bytes

Breakdown of per-packet security fields:
  securityControl (1) + timestamp (8) + nonce (4) = 13 bytes
  ECDSA signature                                  = 64 bytes
  certLength field                                 =  2 bytes
  Certificate (amortized over 10 packets)          = ~29 bytes
  -------------------------------------------------------
  Average overhead                                 = ~108 bytes
