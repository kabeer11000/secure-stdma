====================================================
Date:       2026-05-31

NS-3:       3.18 (optimized build)
Test Suite: stdma-integration

This test exercises the FULL security path inside a live NS-3 discrete-event
simulation — not just the crypto layer in isolation. It proves that:

  TX path: StdmaMac::DoTransmit signs each packet header with ECDSA P-256
           and embeds the X.509 certificate every 10th packet.

  PHY path: Packet travels over an 802.11p channel between two simulated nodes.

  RX path: StdmaMac::Receive validates the timestamp, verifies the ECDSA
           signature (using the in-band certificate or the neighbor cache),
           and only then fires the Rx trace. An Rx trace firing is therefore
           proof of end-to-end authenticated delivery.
